## NIST AI RMF 1.0 + Generative AI Profile — Implementation Guide

### Four Core Functions
| Function | Description | Key Activities |
| -------- | ----------- | -------------- |
| **GOVERN** | Policies and accountability | AI risk policy; roles; culture |
| **MAP** | Risk identification | Context mapping; risk categorization |
| **MEASURE** | Quantify risks | Metrics; benchmarks; testing |
| **MANAGE** | Risk response | Mitigate; monitor; adjust |

### GenAI Profile (NIST-AI-600-1, July 2024)
12 risk areas specific to Generative AI:
1. CBRN information (dangerous knowledge)
2. Confabulation (hallucination)
3. Data privacy
4. Environmental impact
5. Homogenization (monoculture risk)
6. Human-AI configuration
7. Information integrity
8. Information security
9. Intellectual property
10. Obscene/abusive content
11. Societal impacts
12. Value chain / supply chain

### Implementation Roadmap
**30 days**: Create GOVERNANCE/ with risk register; identify AI risks in MAP
**60 days**: Implement MEASURE benchmarks (this suite); baseline all metrics
**90 days**: MANAGE — assign owners to all red/yellow risks; begin remediation
**Ongoing**: Monthly benchmark runs; quarterly stakeholder reviews

### Maturity Score
- 100%: All four functions fully implemented
- 75%: MEASURE gap — implement benchmark suite (done!)
- 50%: MAP + MEASURE gaps — needs risk identification
- 25%: GOVERN only — policy without implementation
